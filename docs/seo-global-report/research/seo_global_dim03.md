### 2.3 Step-by-Step "How to Build a Koi Pond" Content Optimization

The featured snippet for this query is typically a numbered list. Optimized structure based on analysis of top-ranking content [^364^][^368^][^371^]:

**10 Steps to Build a Koi Pond:**
1. Plan Ahead (location, sun exposure, avoid tree roots)
2. Excavate (tiers/shelves, minimum 4ft depth)
3. Place Equipment (skimmer, falls, filtration)
4. Install Underlay/Liner (45 mil EPDM)
5. Adhere Liner (lap sealant to skimmer)
6. Rock In (larger pieces first, edge stones)
7. Foam in Stream (waterfall foam between rocks)
8. Connection (skimmer pump to spillway)
9. Fill & Start (dechlorinator + beneficial bacteria)
10. Finishing Touches (plants, fish after water stabilizes)

**Critical SEO elements for featured snippet capture:**
- Use clear H2/H3 hierarchy
- Include numbered steps with concise descriptions
- Add schema markup (HowTo schema)
- Embed video tutorial (YouTube integration)
- Include cost calculator tool (interactive element)
- Add FAQ section below steps
